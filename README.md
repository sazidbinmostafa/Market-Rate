# 🛒 বাজার দর (BazarDor)

## 📖 Short Description
**BazarDor (বাজার দর)** is a  web application that shows **real-time product prices** from different markets in Bangladesh.  
Users can explore categories, track daily price changes, and view detailed bazar‑wise breakdowns.

---

## ⭐ 5 Key Features
1. **Responsive Design** → Works seamlessly on mobile, tablet, and desktop.  
2. **Navbar with Bangla Date + Price Ticker** → Category links, auth buttons, and scrolling price updates.  
3. **Product Sections** → Top 6 risers, top 6 fallers, and all products grid with Bengali numerals.  
4. **Protected Product Details Page** → Requires login, shows min/max/avg prices with bazar‑wise breakdown.  
5. **Authentication System** → Sign in, sign up, social login (Google/GitHub), with toast notifications.  

---

## 🛠️ Technologies Used
- **Next.js (App Router)** → UI & Routing
- **Tailwind CSS + Hero UI** → Styling & Responsiveness
- **TypeScript / JavaScript** → Core logic
- **BetterAuth** → Authentication (Email/Password + Google/GitHub)
- **React Hot Toast** → Notifications
- **MongoDB** → Database
- **Vercel** → Deployment
